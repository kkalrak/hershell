    에이전트 간 메시지 전달

    다른 셸에서 실행 중인 에이전트에게 메시지를 보냅니다. 상대 상태와 관계없이 즉시 입력하고 제출합니다.

    웹 테스트 브라우저

    에이전트 전용 브라우저를 별도 창으로 열어 사이트를 확인하고 클릭·입력·스크린샷 촬영을 할 수 있습니다. ID별 로그인과 저장소가 분리되며 같은 ID로 다시 열면 이전 상태를 복원합니다.

    텔레그램

    개인 채팅의 지시를 대표 셸 하나에 전달합니다. 왼쪽 셸을 우클릭해 대표를 지정하세요. 같은 봇을 쓰는 기존 릴레이는 먼저 종료하세요.
